## ⭐️CDN（e.g. Akamai）のキャッシュ検証時の注意点

例えば、`example.com`のキャッシュ設定を変えたので動作テストをしたい場合。

以下のように別々のリクエストを投げた場合、それぞれのcurlで新しいTCPコネクション（`3-way handshake` + `TLSハンドシェイク`）を張り直す。

Akamaiクラスタ内のどのマシンに割り振られるかが接続の度に変わりうる。

=> 一連の流れでテストしたい場合に動作が安定しない可能性

```
curl url1
curl url2
curl url3
```

そこで、以下のようにリクエストをまとめる。

```
curl url1 url2 url3
```

同じTCPコネクション（HTTP/2なら1本の接続を多重化）を使い回すため、必ず同じマシンにルーティングされる。

=> 動作テストの結果が安定する。

教訓: CDNのキャッシュ挙動を検証するときは、同一接続内で連続アクセスする方法でないと、単発リクエストの結果だけでは誤った結論を出しかねない。
