## ⭐️GitHub Appとは？

外部アプリや自動化ツールにGitHubを連携させるための、"公式推奨の"仕組み。

- 属人化の排除
    - 個人のアカウントに紐付かないため、担当者の退職や移動で連携が壊れない
- コストと手間の削減
    - ダミーのユーザーアカウントを作る必要がなく、ライセンス枠の消費やパスワード管理が不要
- 高い安全性
    - リポジトリ単位で「この操作だけ」という最小限の権限を設定できる

要は、外部システムからGitHubを安全に自動操作させたい場合の最適解。

## git archive

> Git管理下のファイル一式から.gitディレクトリなどを除外して、zipやtar形式のアーカイブを作成できるコマンド

e.g.

```shell
# 最新のコミット（HEAD）をZIPで出力する
git archive --format=zip -o archive.zip HEAD
```

## ⭐️Mergiraf

https://mergiraf.org/

Git のマージコンフリクトを**構文木（AST）ベース**で解決するツール。Git 標準は「行」しか見ないが、Mergiraf は言語の文法を理解して両者の変更を突き合わせる。

- git の merge driver として登録すると `merge` / `rebase` / `cherry-pick` / `revert` に自動で効く
- 後から手動で呼べて、`mergiraf review` で解決結果を確認できる
- 効くのは「import 行の追加」「リスト末尾への追加」など**行としては衝突するが意味は衝突していない**パターン
- 同じ式を両者が書き換えた場合は当然コンフリクトのまま残る。**判断が要る競合を人間に残すため**のツール
