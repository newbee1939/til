## ⭐️Cloudflare: MCP server portals

https://developers.cloudflare.com/cloudflare-one/access-controls/ai-controls/mcp-portals/

複数の MCP サーバーを **1 つの URL（`/mcp`）に束ねる窓口**。入口の Cloudflare Access で、認証・ツールの絞り込み・ログをまとめて扱う。

```
Client → portal → Access でログイン → 許可されたツールだけ見える
       → "github_list_issues" を呼ぶ
       → portal が "github" + "list_issues" に分解し、GitHub サーバーへ list_issues を転送
```

- ツール名は portal が自動で `{サーバーID}_{元のツール名}` に付け替える。どのサーバーのツールかを名前で見分けるためで、複数のサーバーに同じ名前のツールがあっても衝突しない
- 分解は最初の `_` で行う。そのため元のツール名に `_` があっても問題ないが、サーバーID には `_` を使えない（`-` を使う）
