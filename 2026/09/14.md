## gh auth setup-git

https://cli.github.com/manual/gh_auth_setup-git

### 概要

> This command configures git to use GitHub CLI as a credential helper.

> gh auth setup-git は、GitがGitHubへのアクセス（git push や git pull など）を行う際に、GitHub CLI（gh）を Gitの認証ヘルパー として使用するように設定するコマンドです

### 主な役割とメリット

- 自動認証: リモート操作で認証が必要になった際、Gitが自動で gh の認証情報を利用するため、手動でパスワードやパーソナルアクセストークン（PAT）を入力する必要がなくなる
