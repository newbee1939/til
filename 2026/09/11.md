## sha256sum -c

チェックサムファイルを読み、ファイルが改ざん・破損していないか検証する。

```sh
echo hi > a.txt
sha256sum a.txt > sums && cat sums  # "<ハッシュ>  a.txt" の形で保存される
sha256sum -c sums; echo $?          # a.txt: OK / 0
echo x >> a.txt                     # 1文字足して「改ざん」する
sha256sum -c sums; echo $?          # a.txt: FAILED / 1
```

- `-c`（`--check`）: 引数のファイルを「ハッシュ一覧」として読み、1行ずつ照合する。付けないとハッシュを計算して表示するだけ
- `$?`: 直前のコマンドの終了コード。`0` = 成功、それ以外 = 失敗
- 1文字変えただけでハッシュは全く別物になる → 少しの変更でも検知できる
- 1つでも不一致なら終了コード 1
