## new Array(3).fill([]) と Array.from({length:3}, () => [])

どちらも「長さ3の配列の配列」に見えるが、中身の参照が違う。

```js
const a = new Array(3).fill([]);
a[0].push("x");
console.log(a); // [["x"], ["x"], ["x"]]  ← 全部同じ配列

const b = Array.from({ length: 3 }, () => []);
b[0].push("x");
console.log(b); // [["x"], [], []]
```

`fill()` は**評価済みの値を1つ**受け取ってコピーするので、3要素すべてが同じ配列オブジェクトを指す。
`Array.from` の第2引数はコールバックなので、要素ごとに呼ばれて**毎回新しい配列**ができる。
