## dscacheutil

macOS の Directory Service キャッシュ（ユーザー/グループ/ホスト名など）を問い合わせるツール。

```shell
dscacheutil -q host -a name example.com   # 名前解決
```

### dig との違い

`dig` は DNS サーバーに直接聞く。`dscacheutil` は OS のリゾルバ経由なので `/etc/hosts`・mDNS・VPN の split DNS も効き、**アプリが実際に見る答え**が返る。「dig では引けるのに繋がらない」ときはこちらを使う。

要は、サービス（ローカル環境含めて）が実際に見ているDNSの結果が分かる。

### フラッシュ

```shell
sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder
```

DNS のキャッシュ実体は mDNSResponder 側。`-flushcache` だけでは消えない。

### 補足

- カテゴリは host / user / group / service / protocol / rpc / mount。`-a` 省略で全件
