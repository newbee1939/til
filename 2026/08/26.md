## ⭐️Cloud SQL IAM認証について

参考: https://dev.classmethod.jp/articles/cloud-sql-iam-authentication/
参考: https://docs.cloud.google.com/sql/docs/mysql/iam-authentication?hl=ja

### 概要

Cloud SQLに対して、パスワード認証ではなく`IAM`と`アクセストークン`による認証で接続する。

パスワード管理が不要になるのでより安全。（パスワードが漏洩する心配がない）

### 流れ

1. 接続用サービスアカウントの作成
2. サービスアカウントにCloud SQL クライアントの権限を付与
3. Cloud SQLでIAM認証を有効化

```shell
gcloud sql instances patch example-instance \
    --database-flags=cloudsql.iam_authentication=on
```

4. 作成したサービスアカウントを Cloud SQL のユーザーとして追加
5. サービスアカウント（IAMユーザー）に対して、データベースに対する操作権限を付与
