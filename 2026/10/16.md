## mise Bootstrap

`mise bootstrap` で、mise の設定からマシンを丸ごとセットアップする（パッケージ、dotfiles、サービス、ツールなど）。

- 設定は `[bootstrap.packages]` や `[bootstrap.files]` などに書く
- 設定どおりの部分はスキップされるので、何度実行しても安全
- `--dry-run` で事前確認、`mise bootstrap status` で結果確認

参考:

- [私物Macと仕事Macのdotfilesとアプリ管理をmise bootstrapで管理しやすくした](https://blog.shibayu36.org/entry/2026/10/13/173000)
- [mise: Bootstrap](https://mise.jdx.dev/bootstrap.html)

## Claude Code `/tui fullscreen`

Claude Code CLIの「フルスクリーンレンダリングモード」に関する概要と操作方法です。

### 概要

- 目的: 長い会話時の画面のちらつき（フリッカー）をなくし、メモリ使用量を一定に保つ。
- 仕組み: vimなどのように端末の「代替スクリーンバッファ」を使用して描画する。
- 状態: リサーチプレビュー機能。

### 有効化 / 無効化

- 有効化: 会話中に `/tui fullscreen` を実行（コンテキストは保持されたまま再起動）。
  - または環境変数 `CLAUDE_CODE_NO_FLICKER=1 claude` で起動。
- 無効化: `/tui default` を実行してクラシックレンダラーに戻す。

### 主な機能と操作

- マウスサポート:
  - クリックでカーソル移動、サジェストやメニューの選択、結果の展開が可能。
  - `Cmd` / `Ctrl` + クリックでURLやファイルを開く。
  - ドラッグでテキスト選択（自動的にクリップボードにコピーされる）。
- スクロール: マウスホイール、`PgUp / PgDn`、`Ctrl+Home / End` で移動。
- トランスクリプトモード (`Ctrl+o`):
  - `/` で会話内の検索。
  - `[` で会話を端末のネイティブスクロールバックに出力。
