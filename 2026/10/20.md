## CGO_ENABLED=0

Go で C のライブラリを使わずにビルドする設定。OS の C ライブラリに依存しない単体のバイナリになるので、distroless のような小さいイメージでも動く。

参考: https://pkg.go.dev/cmd/cgo

### 逆に CGO_ENABLED=1 だと

`import "C"` で C のコードやライブラリ（SQLite など）を Go から呼べる。

## Cloud Run は amd64

Cloud Run のコンテナは Linux の amd64（x86-64）向けにビルドする必要がある。

> Executables in the container image must be compiled for Linux 64-bit. Cloud Run specifically supports the Linux x86_64 ABI format.

- amd64: Intel / AMD の CPU の命令セット（CPU が理解する機械語の種類）
- arm64: Apple Silicon やスマホの CPU の命令セット
- 機械語は CPU ごとに別物。M1 Mac でビルドするなら `GOARCH=amd64` を指定する

参考: https://cloud.google.com/run/docs/container-contract

## HTTPS 通信には通信元にも CA 証明書が要る

HTTPS では、相手のサーバー証明書が信頼できる認証局（CA）の署名付きかを通信元が確かめる。その「信頼できる CA の一覧」が CA 証明書。

- 無いと `x509: certificate signed by unknown authority` で失敗する
- Go は OS の置き場所（`/etc/ssl/certs/` など）から読む
- distroless/static には最初から入っている

参考: https://github.com/GoogleContainerTools/distroless/blob/main/base/README.md
