## トークン消費85％減　Googleが脆弱性を自動修正するオープンソースハーネス「Mantis」公開

https://atmarkit.itmedia.co.jp/ait/articles/2609/30/news056.html

https://github.com/google/mantis

脆弱性の発見 → 検証 → 再現 → 修正を AI エージェントに回させるための skill 集と、その参照実装（ADK 製ハーネス）。Apache-2.0、Google の公式サポート製品ではない。

```
history → structural-index → architecture → threat-model → plan
  → researcher → dedupe → review → critic → reproduce → chain
  → patch → calibrate → reflect → report →（次の周回へ）
```

- 要約を下から積む: `/mantis-summarize` がディレクトリごとに `mantis-summary.md` を作り、親は子の要約を読んで自分の要約を書く。後段は全ファイルではなく要約を読むので、トークンが減る（85％超減は Google の主張。README に数値はない）
- 誤検知を多段で削る: dedupe → review → critic で絞り、最後に `/mantis-reproduce` が隔離環境で実際に再現させる。修正も「本当に直ったか」を攻撃側の役に確かめさせる
- 深刻度を付け直す: LLM は何でも critical にしがちなので、`/mantis-calibrate` が基準表に沿って採点し直す
- 導入: `npx skills add google/mantis`。Gemini CLI / Antigravity CLI / ADK 以外のエージェントでも動く
- 注意: AI が書いたコードを自動で実行するので、本番や社内ネットワークに届かない隔離環境で動かす（gVisor + `--network=none` を推奨）。再現できない＝誤検知ではなく、再現できた＝悪用可能でもない。報告前に人が確認する

関連: Cloudflare も同じく「AI の誤検知をどう間引くか」に重心を置いていた（knowledge-flow 2026-09-05）
